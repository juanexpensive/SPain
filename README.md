# SPain

SPain is a small data app focused on exploring the evolution of appraised free-market housing value across Spanish provinces over time using public data.

## Current Data Source

The project currently uses the official MIVAU provincial dataset for `valor tasado medio de vivienda libre`.

Current characteristics of this source:

- territorial level: provinces
- frequency: quarterly
- historical coverage available in the workbook: from `1995` to `2026-Q1`
- source format: official XLS workbook published by MIVAU
